# Release evidence

For every staging or production candidate, attach the immutable commit SHA, migration status, CI URL, container scan results, content inventory, smoke-test output, provider test event IDs, backup SHA-256, isolated restore result, cookie/CORS validation, rollback exercise, and named approvers. Evidence belongs in the private release system; secrets and customer data must never be committed.

Enrollment remains closed unless every applicable item in `PRODUCTION_READINESS.md` has evidence. Repository automation cannot manufacture provider, legal, security, accessibility, educational, or operational approval.
